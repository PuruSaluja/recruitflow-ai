# Fonts for the PDF reports

All unmodified. A report draws each character in the first of these that has
it: DejaVu Sans, then Droid Sans Fallback, then Nanum Square, then Noto Sans
Devanagari and Noto Sans Thai.

**DejaVu Sans 2.37**, regular and bold: Latin, Greek, Cyrillic, Armenian,
Georgian. From the DejaVu project's release archive `dejavu-fonts-ttf-2.37.zip`
(https://github.com/dejavu-fonts/dejavu-fonts/releases/tag/version_2_37,
SHA-256 `7576310b219e04159d35ff61dd4a4ec4cdba4f35c00e002a136f00e96a908b0a`).
Licence (Bitstream Vera and Arev terms, redistribution allowed with the notice)
in [`LICENSE-DejaVu`](LICENSE-DejaVu), copied from the same archive.

**Droid Sans Fallback Full** (Android 6.0.1 r16), one weight: Chinese
characters, Japanese kana. From Debian's `fonts-droid-fallback_6.0.1r16-1.1_all.deb`
(SHA-256 `d2096d4edde128fedf6749be2dd204a5810210a6201126d99b8d412344f71056`,
as listed in Debian bookworm's package index). Apache License 2.0: Debian's
copyright file and the licence's full text are in
[`LICENSE-DroidSansFallback`](LICENSE-DroidSansFallback).

**Nanum Square**, regular and bold: Korean Hangul. From Debian's
`fonts-nanum_20200506-1_all.deb` (SHA-256
`5e86c346e6485b694e1f0ebd27132892fcf014d1b975de4fd21d1654ddf37043`, as listed
in Debian bookworm's package index). SIL Open Font License 1.1, in Debian's
copyright file: [`LICENSE-Nanum`](LICENSE-Nanum).

**Noto Sans Devanagari 2.007**, regular and bold: Devanagari. The unhinted TTFs
from the Noto project's release archive `NotoSansDevanagari-v2.007.zip`
(https://github.com/notofonts/devanagari/releases/tag/NotoSansDevanagari-v2.007,
SHA-256 `820c7da45b1e63562cb41c0a8cac5d9a4202312043a3a040ed1325857ef469b1`).
SIL Open Font License 1.1, no reserved font name, copied from the same archive:
[`LICENSE-NotoSansDevanagari`](LICENSE-NotoSansDevanagari).

**Noto Sans Thai 2.002**, regular and bold: Thai. The unhinted TTFs from
`NotoSansThai-v2.002.zip`
(https://github.com/notofonts/thai/releases/tag/NotoSansThai-v2.002, SHA-256
`af889cc673fc714060ce5e4e088fbad32aa4c0571a19958efeaff128a22da485`). SIL Open
Font License 1.1, no reserved font name, copied from the same archive:
[`LICENSE-NotoSansThai`](LICENSE-NotoSansThai).
